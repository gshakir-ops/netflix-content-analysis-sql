# Raw Dataset

Place the original source file in this directory as `netflix_titles.csv`.

The third-party CSV is not committed to this repository. Keep the source file unchanged; the SQL setup script performs cleaning and normalization.

Expected columns: `show_id`, `type`, `title`, `director`, `cast`, `country`, `date_added`, `release_year`, `rating`, `duration`, `listed_in`, `description`.

Source: Netflix Movies and TV Shows dataset on Kaggle.
